# 32. 最长有效括号

## 题目描述
给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

## 思路解析

这是一道经典的动态规划（DP）题目。

### 状态定义
`dp[i]` 表示：**以 `s[i]` 结尾的**最长有效括号子串的长度。
显而易见，如果 `s[i] == '('`，它不可能是有效子串的结尾，所以 `dp[i] = 0`。我们只看 `s[i] == ')'` 的情况。

### 状态转移
当 `s[i] == ')'` 时，有两种情况能形成有效括号：

1.  **直接匹配 `()`**：
    *   如果 `s[i-1] == '('`，说明构成了一对。
    *   `dp[i] = dp[i-2] + 2`。

2.  **嵌套匹配 `))`**：
    *   如果 `s[i-1] == ')'`，说明我们可能在结束一个嵌套结构，比如 `((...))`。
    *   我们需要跳过以 `i-1` 结尾的有效子串（长度为 `dp[i-1]`），检查它前面的那个字符。
    *   位置 `j = i - dp[i-1] - 1`。
    *   如果 `s[j] == '('`，说明匹配成功！
    *   `dp[i] = dp[i-1]` (内部长度) `+ 2` (这对括号) `+ dp[j-1]` (这整个结构之前的有效长度)。

## 复杂度分析
*   **时间复杂度**：O(N)，遍历一次字符串。
*   **空间复杂度**：O(N)，需要一个 dp 数组。
