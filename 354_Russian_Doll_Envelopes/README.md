# 354. 俄罗斯套娃信封问题

## 题目描述
给你一个二维整数数组 `envelopes` ，其中 `envelopes[i] = [wi, hi]` ，表示第 i 个信封的宽度和高度。
当另一个信封的宽度和高度都比这个信封大的时候，这个信封就可以放进另一个信封里。
请计算最多能有多少个信封能组成一组“俄罗斯套娃”信封。

## 思路解析

这道题其实是**最长递增子序列 (LIS)** 的二维变体。

### 1. 降维打击（排序）
如果我们把信封按**宽度 w 升序排序**，那么在宽度上，后面的信封肯定大于等于前面的信封。
此时，问题就简化成了：在排序后的信封序列中，找**高度 h 的最长递增子序列**。

**关键技巧**：
如果两个信封宽度相同，比如 `[6, 7]` 和 `[6, 4]`，它们能互相嵌套吗？不能！
但如果我们只看高度，求 LIS 时 `4` 可能会接在 `7` 后面（如果我们按 h 升序排），这就算错了。
**解决办法**：当宽度相同时，**按高度 h 降序排序**。
这样 `[6, 7], [6, 4]` 在数组里的顺序就是这样。因为求的是“严格递增”子序列，`4` 不可能接在 `7` 后面，从而避免了宽度相同情况下的错误计数。

### 2. 最长递增子序列 (LIS)
处理完排序后，我们只需要对高度数组求 LIS。
使用 **贪心 + 二分查找**（Patience Sorting）的方法，时间复杂度为 O(N log N)。

*   维护一个 `top` 数组，`top[i]` 表示长度为 `i+1` 的 LIS 的末尾元素的最小值。
*   遍历每个数字，用二分查找在 `top` 中找到第一个大于等于它的位置并替换；如果没找到，就追加到末尾。

## 复杂度分析
*   **时间复杂度**：O(N log N)，排序 O(N log N) + LIS O(N log N)。
*   **空间复杂度**：O(N)，用于存储高度数组和 LIS 辅助数组。
