# 46. 全排列

## 题目链接
[LeetCode Link](https://leetcode.cn/problems/permutations/solutions/)

## 解题思路
### 回溯法 (Backtracking)
全排列问题是典型的**回溯算法**应用场景。
我们可以把它看作是一棵**决策树**：
*   根节点：还没选任何数字。
*   第一层：选了 `1`，剩下 `[2, 3]`。
*   第二层：选了 `2`，剩下 `[3]`。
*   ...

**通用模板**：
1.  **路径** (`track`)：记录已经做出的选择。
2.  **选择列表** (`nums`)：当前还可以做的选择。
3.  **结束条件**：当路径长度等于 `nums` 的长度时，说明找到了一个排列。

关键在于**撤销选择**：
当我们递归完一个分支（比如 `[1, 2, 3]`）后，我们需要把 `3` 拿出来，把 `2` 拿出来，回到上一层，才能去选别的数字（比如 `[1, 3, 2]`）。
这就是 `track.pop_back()` 和 `used[i] = false` 的作用。
