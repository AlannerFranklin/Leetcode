# 165. 比较版本号

## 题目描述
给你两个版本号字符串 `version1` 和 `version2` ，请你比较它们。
比较规则：按从左到右的顺序依次比较它们的修订号。忽略前导零。如果其中一个版本字符串的修订号较少，则将缺失的修订号视为 0。

## 思路解析

这道题最直接且高效的方法是**双指针法**。

### 核心逻辑
1.  使用两个指针 `i` 和 `j` 分别指向两个字符串的开头。
2.  在一个大循环中遍历，条件是 `i < n || j < m`（只要有一个没走完就继续）。这样可以自动处理长度不一致的情况（短的默认为 0）。
3.  在每轮循环中：
    *   计算 `version1` 当前点号之前的数值 `num1`。
    *   计算 `version2` 当前点号之前的数值 `num2`。
    *   比较 `num1` 和 `num2`，如果不相等直接返回结果。
    *   跳过点号，准备处理下一段。

### 优点
*   不需要将字符串分割（Split）成数组，节省空间。
*   直接计算数值，避免了多次字符串转数字的开销。
*   逻辑清晰，自然处理了前导零和版本号长度不同的问题。

## 复杂度分析
*   **时间复杂度**：O(max(N, M))，N 和 M 是两个字符串的长度。
*   **空间复杂度**：O(1)，只使用了几个变量。
