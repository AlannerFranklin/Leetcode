# 3. 无重复字符的最长子串 (Longest Substring Without Repeating Characters)

## 题目描述
给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

## 解题思路

### 核心思想：滑动窗口 (Sliding Window)
这道题是经典的滑动窗口问题。我们可以维护一个窗口 `[left, right]`，保证窗口内的字符都不重复。

1.  **扩张窗口 (`right`)**：
    右指针 `right` 向右移动，尝试把新的字符 `s[right]` 加入窗口。

2.  **收缩窗口 (`left`)**：
    如果在加入 `s[right]` 之前，发现窗口里已经有了这个字符（即出现重复），说明如果不把原来的那个重复字符移出去，新字符就加不进来。
    *   **怎么移？** 我们需要移动左指针 `left`，并从集合中删除 `s[left]`。
    *   **移多少？** 需要一直移，直到窗口里没有 `s[right]` 这个字符为止。

3.  **更新结果**：
    每次成功加入新字符后，当前窗口的长度就是 `right - left + 1`，我们用它来更新最大长度 `max_length`。

### 踩坑点 (Pitfalls)
1.  **删除的对象**：
    当发现重复时，不能只删 `window.begin()` 或者随便删一个。必须删的是窗口最左边的元素 `s[left]`。

2.  **循环删除**：
    不能只删一次。例如 `abca...` 遇到第二个 `a`，删掉第一个 `a` 即可。但如果是 `abcb...` 遇到第二个 `b`，我们需要先删 `a`，再删 `b`，才能把新 `b` 放进来。所以要用 `while` 循环。

3.  **哈希集合操作**：
    *   查找：`window.find(ch) != window.end()`
    *   删除：`window.erase(key)`
    *   插入：`window.insert(key)`

### 复杂度
*   **时间复杂度**：O(N)。虽然有两层循环（外层 `for`，内层 `while`），但每个字符最多被 `add` 一次，被 `remove` 一次，所以总操作次数是线性的。
*   **空间复杂度**：O(min(N, M))，其中 M 是字符集的大小（例如 ASCII 128）。我们需要一个哈希集合来存储窗口内的字符。
