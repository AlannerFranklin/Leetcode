# 200. 岛屿数量

## 题目链接
[LeetCode Link](https://leetcode.cn/problems/number-of-islands/)

## 解题思路
### 沉岛策略 (Sinking Strategy)
这道题的核心是**如何防止重复计算**。当我们找到一个岛屿的一部分时，我们需要把属于这个岛屿的所有陆地都标记为“已访问”。

最直观的方法就是**沉岛**：
1.  遍历整个二维网格。
2.  当我们遇到一个 `'1'` (陆地) 时：
    *   计数器 `count` 加 1。
    *   启动 **DFS (深度优先搜索)**。
3.  在 DFS 中：
    *   把当前格子变成 `'0'` (沉没)。
    *   递归地去“淹没”它上下左右相邻的陆地。
4.  这样，下次遍历到这个岛屿的其他部分时，它们已经是 `'0'` 了，就不会被重复计数。

这种方法不需要额外的 `visited` 数组，直接修改原数组即可，空间复杂度更优。
