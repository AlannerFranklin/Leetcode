# 41. 缺失的第一个正数

## 题目描述
给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。
请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

## 思路解析

这道题的难点在于**O(n) 时间**和**O(1) 空间**的限制。常规的哈希表虽然能满足时间复杂度，但空间复杂度是 O(n)。

### 原地哈希 (In-place Hashing)
我们可以利用原本的数组 `nums` 作为哈希表。
**规则**：数值为 `x` 的元素应该放在索引 `x-1` 的位置上。（例如：1 放在 nums[0]，2 放在 nums[1]）。

1.  **归位**：
    遍历数组，对于每个数字 `nums[i]`，如果它满足以下条件，就将它交换到正确的位置 `nums[i] - 1` 上：
    *   是正数 (`nums[i] > 0`)
    *   在有效范围内 (`nums[i] <= n`)
    *   还没在正确的位置上 (`nums[i] != nums[nums[i] - 1]`)
    注意使用 `while` 循环，因为交换回来的新数字可能还需要继续交换。

2.  **查找**：
    再次遍历数组，检查每个位置 `i` 上的数字是否是 `i + 1`。
    *   如果不是，说明 `i + 1` 就是缺失的第一个正数。
    *   如果遍历完都正确，说明缺失的是 `n + 1`。

## 复杂度分析
*   **时间复杂度**：O(N)。虽然有 while 循环，但每个数字最多被交换一次放到正确位置，所以均摊是 O(N)。
*   **空间复杂度**：O(1)。只用了常数个额外变量，是在原数组上修改。
