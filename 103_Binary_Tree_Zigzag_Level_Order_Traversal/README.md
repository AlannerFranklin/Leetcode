# 103. 二叉树的锯齿形层序遍历

## 题目描述
给你二叉树的根节点 `root` ，返回其节点值的 **锯齿形层序遍历** 。（即先从左往右，再从右往左进行下一层遍历，以此类推，层与层之间交替进行）。

## 解题思路

### 核心思想：BFS + 结果翻转
这道题本质上就是 **二叉树的层序遍历 (BFS)**。
普通的 BFS 是每一层都从左往右打印。锯齿形遍历只需要在偶数层（或者特定方向时）把结果 **翻转 (Reverse)** 一下即可。

### 步骤
1.  **队列 (Queue)**：BFS 的标准工具。先把 `root` 入队。
2.  **分层处理**：
    *   每次循环开始前，记录 `size = q.size()`，这代表当前层有多少个节点。
    *   用一个 `for` 循环处理这 `size` 个节点，确保一次处理一层。
3.  **方向控制**：
    *   维护一个布尔值 `isLeftToRight`。
    *   如果当前是“从右往左”，则在收集完这一层的 `vector` 后，调用 `std::reverse` 进行翻转。
    *   每层结束，`isLeftToRight` 取反。
4.  **孩子入队**：
    *   **注意**：无论哪一层，孩子入队的顺序永远是 **先左后右**。不要在入队顺序上搞花样，只在收集结果时翻转数值即可。

### 复杂度
*   **时间复杂度**：O(N)。每个节点进出队列一次。虽然有 `reverse`，但总的翻转次数也是线性的。
*   **空间复杂度**：O(N)。队列中最多存一层的节点（满二叉树最底层约为 N/2）。
