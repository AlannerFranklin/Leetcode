# 56. 合并区间

## 题目描述
以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]` 。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

## 思路解析

这道题的核心在于**排序**。

1.  **排序**：首先根据区间的 `start` 进行升序排序。这样可以保证所有重叠的区间都是相邻的。
2.  **遍历合并**：
    *   创建一个 `merged` 数组用于存储结果。
    *   遍历排序后的区间：
        *   如果 `merged` 为空，或者当前区间的 `start` 大于 `merged` 中最后一个区间的 `end`，说明这两个区间不重叠，直接将当前区间加入 `merged`。
        *   否则，说明有重叠。我们需要合并这两个区间，具体做法是更新 `merged` 中最后一个区间的 `end` 为 `max(merged.back()[1], interval[1])`。

## 复杂度分析
*   **时间复杂度**：O(N log N)，主要消耗在排序上。遍历只需要 O(N)。
*   **空间复杂度**：O(log N)，主要是排序所需的栈空间（如果忽略存储结果的 O(N) 空间）。
