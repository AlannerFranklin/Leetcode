# 236. 二叉树的最近公共祖先

## 题目链接
[LeetCode Link](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/description/)

## 解题思路
### 递归法 (DFS)
这道题用递归解非常优雅。我们的核心逻辑是：**对于每一个节点，去左右子树里找 p 和 q**。

1.  **终止条件**：
    *   如果当前节点为空，返回 `null`。
    *   如果当前节点就是 `p` 或 `q`，那它自己就是我们要找的目标（或者是目标的祖先），直接返回它。
2.  **递归搜索**：
    *   去左子树找 `left`。
    *   去右子树找 `right`。
3.  **合并结果**：
    *   如果 `left` 和 `right` **都不为空**：说明 `p` 和 `q` 一个在左边，一个在右边，那当前节点就是它们的**分叉点**（最近公共祖先）。
    *   如果只有一个不为空（比如 `left`）：说明 `p` 和 `q` 都在左子树里，直接把 `left` 传上去。
    *   如果都为空：说明这棵树里没有 `p` 和 `q`。

这种方法只需要遍历一遍树 O(N)，不需要额外的空间存父指针。
