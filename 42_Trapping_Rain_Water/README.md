# 42. 接雨水

## 题目链接
[LeetCode Link](https://leetcode.cn/problems/trapping-rain-water/description/)

## 解题思路
### 双指针法 (Two Pointers)
这道题的核心是**木桶原理**：对于每一根柱子，它能存多少水取决于它左边最高的柱子 (`l_max`) 和右边最高的柱子 (`r_max`) 中**较矮**的那一个。

如果我们从两头向中间遍历：
1.  维护两个指针 `left` 和 `right`，以及两个变量 `l_max` 和 `r_max`。
2.  **关键逻辑**：
    *   如果 `l_max < r_max`：说明左边是短板。虽然右边可能还有更高的山，但对于左边这个位置来说，水位已经被 `l_max` 限制死了。我们可以直接结算左边的水量，然后 `left` 向右移。
    *   如果 `l_max >= r_max`：说明右边是短板。我们可以直接结算右边的水量，然后 `right` 向左移。

这种方法只需要一次遍历 O(N)，空间复杂度是 O(1)，是最优解。
