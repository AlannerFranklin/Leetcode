# 25. K 个一组翻转链表

## 题目描述
给你链表的头节点 `head` ，每 `k` 个节点一组进行翻转，请你返回修改后的链表。
如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

## 解题思路

### 核心思想：分组处理 + 链表拼接
这道题的难点在于**断开**和**重连**。我们需要把链表切成一段一段的，翻转每一段，然后再把它们按顺序接回去。

### 关键步骤
1.  **Dummy Node (虚拟头节点)**：
    *   因为第一组翻转后，整个链表的头节点会变，所以需要一个 `dummy` 指向原来的 `head`，方便最后返回 `dummy->next`。

2.  **指针维护**：
    *   `pre`：指向**上一组翻转后的尾节点**。翻转当前组后，需要让 `pre->next` 指向当前组的新头。
    *   `end`：用来试探当前组是否够 `k` 个节点。
    *   `start`：当前组的开始节点（翻转前的头，翻转后的尾）。
    *   `nextGroup`：下一组的开始节点。

3.  **流程循环**：
    *   **试探**：让 `end` 往后走 `k` 步。如果中途遇到 `nullptr`，说明剩余节点不够一组，直接跳出循环（保持原样）。
    *   **断开**：记录 `nextGroup = end->next`，然后把 `end->next` 设为 `nullptr`，把这一组切下来。
    *   **翻转**：调用标准的链表翻转函数 `reverseGroup(start)`。
    *   **重连**：
        *   `pre->next` 指向翻转后的新头。
        *   `start->next` 指向 `nextGroup`（这一组的尾巴连上下一组的头）。
    *   **更新**：`pre = start`（当前组的尾巴变成下一轮的 `pre`），`end = pre`。

### 复杂度
*   **时间复杂度**：O(N)。每个节点只会被遍历和翻转常数次。
*   **空间复杂度**：O(1)。只用了几个指针，不需要额外空间。
