# 215. 数组中的第K个最大元素

## 题目描述
给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。
你必须设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

## 解题思路

### 核心算法：快速选择 (Quick Select)
这道题是 **快速排序 (Quick Sort)** 的变种。
快排每次把数组分成两半，然后递归处理**两边**。
快速选择每次把数组分成两半，但只递归处理**包含目标下标的那一边**。
因为每次只处理一半，所以平均时间复杂度是 **O(N)**。

### 关键优化点 (防止超时)
LeetCode 的测试用例包含两种极端情况，必须处理才能过：

1.  **有序数组 (Sorted Array)**：
    *   如果每次选第一个数做 pivot，复杂度会退化成 O(N^2)。
    *   **解决**：**随机化 Pivot**。在 partition 开始前随机选一个数交换到头部。

2.  **大量重复元素 (Duplicate Elements)**：
    *   如果数组全是 `[2, 2, 2, ...]`，普通的 partition (带等号) 会让一个指针跑到底，导致划分极不平衡，退化成 O(N^2)。
    *   **解决**：**双向扫描且不带等号**。
        *   `while (nums[i] < pivot)`：遇到相等就停。
        *   `while (nums[j] > pivot)`：遇到相等就停。
        *   这样重复元素会被强制交换到两边，保证 partition 依然是从中间切开的。

### 复杂度
*   **时间复杂度**：平均 O(N)，最坏 O(N^2)（但在上述优化下极难触发）。
*   **空间复杂度**：O(log N) 或 O(N)（递归栈深度）。
