# 1461. 检查一个字符串是否包含所有长度为 K 的二进制子串

## 题目链接
[LeetCode Link](https://leetcode.cn/problems/check-if-a-string-contains-all-binary-codes-of-size-k/?envType=daily-question&envId=2026-02-23)

## 解题思路
### 逆向思维 + 哈希集合
如果我们尝试生成所有 $2^k$ 个二进制串去匹配，当 $k=20$ 时会超时。
所以我们反过来：**直接统计 `s` 中包含了多少种不同的长度为 `k` 的子串。**

1.  **滑动窗口**：遍历字符串 `s`，每次取长度为 `k` 的子串 `s.substr(i, k)`。
2.  **去重统计**：把这些子串放入 `unordered_set` 中。
3.  **判断结果**：如果集合的大小等于 $2^k$（即 `1 << k`），说明所有可能的组合都出现过了。

### 剪枝优化
如果 `s` 的长度非常短，根本凑不够 $2^k$ 个子串，可以直接返回 `false`。
例如：`s` 长度 10，`k=5`（需要 32 个），哪怕 `s` 里全是不同的子串也才 6 个，肯定不够。
这个判断对于 $k$ 很大的情况非常关键。
