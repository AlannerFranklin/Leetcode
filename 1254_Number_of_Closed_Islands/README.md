# 1254. 统计封闭岛屿的数目 (Number of Closed Islands)

[LeetCode 链接](https://leetcode.cn/problems/number-of-closed-islands/)

## 题目描述

二维矩阵 `grid` 由 `0`（土地）和 `1`（水）组成。岛是由最大的4个方向连通的 `0` 组成的群，封闭岛是一个 完全 由 `1` 包围（左、上、右、下）的岛。
请返回 封闭岛屿 的数目。

## 思路解析

你的代码思路其实已经非常接近正确答案了！你试图用 DFS 遍历所有靠边的岛屿。

### 核心逻辑：排除法
什么叫“封闭岛屿”？
就是**不靠边**的岛屿。
如果一个岛屿里的任何一块土地接壤到了矩阵的边界（上一行、下一行、左一列、右一列），那么它就不是“封闭”的，因为边界外面被认为是无限延伸的世界，而不是“水”。

所以解题步骤很简单：
1.  **先处理边界**：把所有靠着矩阵四个边界（上、下、左、右）的陆地（`0`），以及和它们连通的陆地，全部变成水（`1`）。这相当于把所有不封闭的岛屿都淹掉了。
2.  **统计剩下的**：此时矩阵中间剩下的 `0`，一定是被 `1` 包围的“封闭岛屿”。遍历矩阵，每遇到一个 `0`，就是一个封闭岛屿，计数加一，然后用 DFS 把这个岛屿淹掉（避免重复计算）。

### 你的代码问题
你给出的代码其实稍微有点混乱，主要在于 `dfs` 函数的调用位置。
正确的逻辑是：
1.  先用两个循环分别处理上下边界和左右边界的 `0`，调用 `dfs` 把它们淹没。
2.  然后再遍历整个矩阵内部，统计剩下的 `0`。

你的代码片段：
```cpp
// 你的代码片段
for (int j = 0;j < n;j++) { 
    dfs(grid, 0, j); 
    dfs(grid, m - 1, j); 
} 
for (int i = 0;i < m;i++) { 
    dfs(grid, i, 0); 
    dfs(grid, i, n - 1); 
} 
```
这部分是对的！这就是在淹没边界岛屿。

然后：
```cpp
for (int i = 0; i < m; i++) { 
    for (int j = 0; j < n; j++) { 
        if (grid[i][j] == 0) { 
            res++; 
            dfs(grid, i, j); 
        } 
    } 
}
```
这也是对的！统计剩下的岛屿。

**所以，你给出的代码其实逻辑是对的！** 只要把那个 `void dfs(...)` 定义在类里面或者外面正确位置即可。
唯一的瑕疵是：你的 `dfs` 函数定义在 `closedIsland` 内部吗？如果是的话，C++ 不允许在函数内部直接定义普通函数（除非用 lambda）。你需要把它作为类的成员函数。

我在 `solution.cpp` 中帮你整理了标准的写法。

## 复杂度分析
*   **时间复杂度**：$O(M \times N)$。每个格子最多被访问一次（要么是变成 1，要么本来就是 1）。
*   **空间复杂度**：$O(M \times N)$。最坏情况下（全都是陆地），递归栈深度可能达到 $M \times N$。
