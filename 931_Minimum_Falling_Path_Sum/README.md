# 931. 下降路径最小和

## 题目描述
给你一个 `n x n` 的方形整数数组 `matrix` ，请你找出并返回通过 `matrix` 的下降路径的最小和。
下降路径可以从第一行中的任何元素开始，并从每一行中选择一个元素。在下一行选择的元素和当前行所选元素最多相隔一列（即位于正下方或者沿对角线向左或者向右的第一个元素）。

## 思路解析

这道题是典型的动态规划问题，可以使用**自底向上**的方法解决，并进行**空间优化**。

### 1. 状态定义
如果不进行空间优化，我们可以定义 `dp[i][j]` 为到达第 `i` 行第 `j` 列的最小路径和。
状态转移方程为：
`dp[i][j] = matrix[i][j] + min(dp[i-1][j-1], dp[i-1][j], dp[i-1][j+1])`
注意处理边界条件（比如第一列没有左上方，最后一列没有右上方）。

### 2. 空间优化（滚动数组）
观察转移方程发现，计算第 `i` 行只需要第 `i-1` 行的数据。因此，我们不需要存储整个 `n x n` 的 dp 矩阵，只需要两个一维数组：
*   `dp`：存储上一行的计算结果。
*   `temp`：存储当前行的计算结果。

每计算完一行，将 `temp` 的内容转移给 `dp`，以此类推，直到最后一行。这样可以将空间复杂度从 O(N^2) 降低到 O(N)。

## 复杂度分析
*   **时间复杂度**：O(N^2)，需要遍历整个矩阵。
*   **空间复杂度**：O(N)，使用了两个长度为 N 的一维数组。
