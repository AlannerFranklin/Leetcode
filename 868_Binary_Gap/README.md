# 868. 二进制间距 (Binary Gap)

## 题目描述
给定一个正整数 `n`，找到并返回 `n` 的二进制表示中两个 **相邻** 1 之间的 **最长距离**。如果不存在两个相邻的 1，返回 0。

## 解题思路

### 核心思想
虽然题目要求的是二进制表示中相邻 1 的距离，我们不需要真正把二进制转成字符串或者数组存起来。我们可以利用**位运算**或者**取余法**直接遍历二进制位。

### 关键点
1.  **遍历顺序**：
    通过 `n % 2` 和 `n /= 2` 可以从**低位到高位**（从右向左）遍历二进制位。虽然顺序是反的，但两个 1 之间的相对距离（下标差的绝对值）是不变的。

2.  **记录上一个 1 的位置 (`left`)**：
    我们需要一个变量 `left` 来记录上一次遇到 1 的索引位置。
    *   **坑点**：`left` 不能初始化为 0。因为第 0 位可能不是 1，或者第 0 位就是我们要找的第一个 1。
    *   **正确做法**：将 `left` 初始化为 `-1`，表示“还没有遇到过 1”。

3.  **计算距离**：
    当我们遇到一个新的 1（当前索引为 `i`）时：
    *   如果 `left != -1`，说明之前已经有过 1 了，计算距离 `i - left` 并更新最大值。
    *   无论是否计算了距离，都要更新 `left = i`，因为对于下一个 1 来说，当前的这个 1 就是它的“上一个”。

### 复杂度
*   **时间复杂度**：O(log n)。因为我们需要遍历 n 的二进制位数，位数约为 log2(n)。
*   **空间复杂度**：O(1)。只使用了常数个变量，不需要额外的数组存储。
