# 160. 相交链表

## 题目链接
[LeetCode Link](https://leetcode.cn/problems/intersection-of-two-linked-lists/description/)

## 解题思路
### 双指针法 (A + B = B + A)
这道题有一个非常巧妙的解法。
我们要找两个链表的交点，但它们长度不一样，不能直接齐头并进。

但是，如果我们让两个指针分别走完自己的路后，**立刻去走对方的路**，那么它们走过的**总路程就是一样的**。
*   `pA` 走的路程：`len(A) + len(B)`
*   `pB` 走的路程：`len(B) + len(A)`

既然总路程一样，速度又一样，那么它们一定会在**终点**（也就是相交点）相遇。如果不相交，它们会同时走到 `NULL`。

这种方法的时间复杂度是 O(N + M)，空间复杂度是 O(1)。
