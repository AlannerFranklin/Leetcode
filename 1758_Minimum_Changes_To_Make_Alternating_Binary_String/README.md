# 1758. 生成交替二进制字符串的最少操作数 (Minimum Changes To Make Alternating Binary String)

[LeetCode 链接](https://leetcode.cn/problems/minimum-changes-to-make-alternating-binary-string/)

## 题目描述

给你一个仅由字符 '0' 和 '1' 组成的字符串 s 。一步操作中，你可以将任一 '0' 变成 '1' ，或者将 '1' 变成 '0' 。
交替字符串 定义为：如果字符串中不存在相邻两个字符相等的情况，那么该字符串就是交替字符串。
返回使 s 变成 交替字符串 所需的 最少 操作数。

## 思路解析

### 1. 你的解法 (两次遍历)
你通过两次遍历分别计算了变成 "0101..." 和 "1010..." 所需的操作数，然后取最小值。
这完全正确，逻辑也很清晰。

### 2. 更简单的解法 (一次遍历 + 数学规律)
我们注意到交替字符串只有两种可能：
1.  以 '0' 开头：`010101...`
2.  以 '1' 开头：`101010...`

这两种情况是**完全互补**的。
对于字符串中的任意一个位置 `i`：
*   如果它匹配了第一种情况（不需要修改），那么它在第二种情况里必然不匹配（需要修改）。
*   如果它不匹配第一种情况（需要修改），那么它在第二种情况里必然匹配（不需要修改）。

**结论**：
如果变成第一种情况需要 `cnt` 次操作，那么变成第二种情况必然需要 `n - cnt` 次操作（`n` 是字符串长度）。

**优化**：
我们只需要计算变成其中一种情况（比如以 '0' 开头）的操作数 `cnt`，最后的答案就是 `min(cnt, n - cnt)`。

### 代码实现 (优化后)

```cpp
class Solution {
public:
    int minOperations(string s) {
        int cnt = 0;
        int n = s.length();
        for (int i = 0; i < n; ++i) {
            // 目标模式：010101...
            // 下标 i 为偶数时应为 '0'，奇数时应为 '1'
            // 即 s[i] 应该等于 i % 2 对应的字符
            if (s[i] - '0' != i % 2) {
                cnt++;
            }
        }
        return min(cnt, n - cnt);
    }
};
```

## 复杂度分析
*   **时间复杂度**：$O(N)$，只需遍历一次。
*   **空间复杂度**：$O(1)$，不需要额外的字符串空间。
