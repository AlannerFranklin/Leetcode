# 滴滴笔试题：方格雨 (Grid Rain)

## 题目描述

方格世界中所有方格的长宽高均为 1 米。方格世界中有 $n$ 个方格堆，编号依次为 $1, 2, \dots, n$。每个方格堆中的方格都是按照从下到上的方式堆成一列。初始时每个方格堆中的方格数量均为 0。

方格世界会下 $m$ 场“方格雨”，第 $i$ 场“方格雨”会使得编号在 $l_i$ 到 $r_i$ 之间的方格堆的方格数量增加 $d_i$。

定义 $f(x)$ 表示经过“方格雨”后方格世界中高度大于等于 $x$ 米的方格堆个数。你需要计算 $f(1), f(2), \dots, f(10^{100})$ 中一共有多少少不同的取值。

### 输入描述
*   第一行有两个整数 $n$ ($1 \le n \le 10^9$) 和 $m$ ($1 \le m \le 10^5$)，分别表示方格堆的个数和“方格雨”的次数。
*   接下来 $m$ 行中，第 $i$ 行有三个整数 $l_i, r_i, d_i$ ($1 \le l_i \le r_i \le n, 1 \le d_i \le 10$)，分别表示“方格雨”作用的方格堆范围和增加的方格数量。

### 输出描述
*   输出一个整数，表示不同取值的个数。

## 题目解析

这道题考察了两个核心知识点：
1.  **差分数组与离散化**（处理大规模区间的更新）。
2.  **数学推导**（$f(x)$ 的性质）。

### 1. 为什么用 `map<int, long long> diff`？

*   **数据范围**：题目中 $n$ 高达 $10^9$，如果直接开一个 `int height[1000000000]` 的数组，内存会直接爆掉（需要 4GB+ 内存）。
*   **稀疏性**：虽然 $n$ 很大，但操作次数 $m$ 只有 $10^5$。这意味着只有最多 $2m$ 个位置的高度发生了相对变化。
*   **解决方案**：使用 `std::map` 来存储**差分数组**。
    *   **差分数组定义**：`diff[i] = height[i] - height[i-1]`。它的性质是：区间 `[l, r]` 增加 `d`，只需要修改两个点：`diff[l] += d` 和 `diff[r+1] -= d`。
    *   **离散化**：因为大部分位置的 `diff` 值都是 0，我们不需要存储它们。用 `map` 只存储非 0 的点，`map` 会自动按键值（位置）排序，完美解决了空间问题。

### 2. 如何还原高度？

有了 `diff` map，我们只需要遍历它，就能还原出每一段的高度。
```cpp
long long cur = 0; // 当前累积高度
int prev = 1;      // 上一个有变化的位置

for (auto const& [pos, delta] : diff) {
    long long len = pos - prev; // 这一段的长度
    if (len > 0) cnt[cur] += len; // 记录高度为 cur 的堆有多少个
    cur += delta; // 更新当前高度
    prev = pos;
}
```
**注意**：`map` 中的 `pos` 是高度发生**变化**的点。在 `prev` 到 `pos` 之间，高度是保持不变的，这就是为什么我们可以直接 `cnt[cur] += len`。

### 3. 核心：为什么答案是 `cnt.size() + 1`？

题目定义 $f(x)$ 为“高度 $\ge x$ 的方格堆个数”。

假设最终非零的高度有 3 种：10, 20, 30。
*   `cnt[10] = A` (有 A 个堆高度是 10)
*   `cnt[20] = B` (有 B 个堆高度是 20)
*   `cnt[30] = C` (有 C 个堆高度是 30)

让我们看看 $f(x)$ 随 $x$ 变化的规律：
*   当 $x \in [1, 10]$ 时：只要高度 $\ge 10$ 都算。$f(x) = A + B + C$。
*   当 $x \in [11, 20]$ 时：高度为 10 的不算了，只有 $\ge 20$ 的算。$f(x) = B + C$。
*   当 $x \in [21, 30]$ 时：只有 $\ge 30$ 的算。$f(x) = C$。
*   当 $x > 30$ 时：没有堆满足条件。$f(x) = 0$。

**结论**：
*   $f(x)$ 是一个阶梯函数。
*   每当 $x$ 跨过一个**存在的非零高度**，$f(x)$ 的值就会减少（减少的量等于该高度的堆数量）。
*   因此，$f(x)$ 的**不同非零取值个数** = **不同非零高度的个数**。
*   题目问的是所有取值（包括 0），所以是 **`cnt.size() + 1`**。

### 总结

这段代码逻辑非常清晰且标准：
1.  利用 `map` 实现离散化差分数组。
2.  扫描一遍还原出所有实际存在的高度。
3.  利用 $f(x)$ 的单调性得出结论：不同取值数 = 不同高度数 + 1。
