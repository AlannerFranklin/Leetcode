# 1404. 将二进制表示减到 1 的步骤数 (Number of Steps to Reduce a Number in Binary Representation to One)

[LeetCode 链接](https://leetcode.cn/problems/number-of-steps-to-reduce-a-number-in-binary-representation-to-one/)

## 题目描述

给你一个以二进制字符串形式表示的数字 `s` 。请你返回将其变换为 `1` 所需要的步骤数。

如果当前数字是偶数，你需要把它除以 2 。
如果当前数字是奇数，你需要把它加 1 。
题目保证你总是可以将其变为 1 。

## 思路解析

这道题如果直接模拟（把字符串转成整数），会遇到整数溢出的问题，因为 `s` 的长度可以达到 500，远远超过 `long long` 的范围。
如果直接用字符串模拟加法和除法，每次操作字符串（尤其是进位导致的 `insert`）开销较大。

**最优解法：一次遍历 + 进位记录**

我们可以从字符串的**最低位（末尾）**向前遍历到**次高位（下标 1）**。最高位（下标 0）最后单独处理。
维护一个变量 `carry` 表示当前的进位状态。

对于当前位 `s[i]`：
1.  **当前值 + 进位 == 1**（奇数）：
    *   例如 `s[i]='1', carry=0` 或者 `s[i]='0', carry=1`。
    *   这就意味着当前数字是奇数。根据规则，我们需要“加 1”然后“除以 2”。
    *   **加 1**：当前位变成 0，并产生进位（carry 变为 1）。
    *   **除以 2**：相当于把末尾的 0 删掉。
    *   **总步数**：+2（加 1 是一步，除 2 是一步）。
    *   **进位**：必然产生进位，`carry = 1`。

2.  **当前值 + 进位 != 1**（偶数）：
    *   例如 `s[i]='0', carry=0`（结果 0）或者 `s[i]='1', carry=1`（结果 2，即二进制 10）。
    *   这就意味着当前数字是偶数（或者加进位后变成了偶数）。
    *   **除以 2**：直接把末尾的 0 移出。
    *   **总步数**：+1。
    *   **进位**：
        *   如果 `0+0`，进位是 0。
        *   如果 `1+1`，进位是 1。
        *   结论：**进位状态保持不变**。

**循环结束后的处理：**
当遍历完 `s[n-1]` 到 `s[1]` 后，剩下的 `s[0]` 肯定是 `'1'`。
*   如果此时 `carry == 1`：说明有一个进位传到了最高位，变成了 `1 + 1 = 10`。这需要再除以 2 一次才能变成 `1`。所以步数 `+1`。
*   如果此时 `carry == 0`：说明没有进位，已经是 `1` 了，不需要额外操作。

### 复杂度分析
*   **时间复杂度**：O(N)，只遍历了一次字符串。
*   **空间复杂度**：O(1)，只用了常数个变量。

## 代码实现

```cpp
class Solution {
public:
    int numSteps(string s) {
        int steps = 0;
        int carry = 0;
        // 从后往前遍历，直到 s[1]
        for (int i = s.size() - 1; i > 0; i--) {
            // 如果当前位 + 进位 是奇数 (1)
            if (s[i] - '0' + carry == 1) {
                steps += 2; // 加1再除2
                carry = 1;  // 产生进位
            } else {
                steps += 1; // 偶数，直接除2
                // carry 不变
            }
        }
        return steps + carry;
    }
};
```
