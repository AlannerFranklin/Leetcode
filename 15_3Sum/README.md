# 15. 三数之和 (3Sum)

## 题目描述
给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 0 且不重复的三元组。

## 解题思路

### 核心思想：排序 + 双指针
暴力法是 O(N^3)，肯定超时。
利用 **排序** 后的性质，我们可以将问题转化为 **O(N^2)** 的解法。

1.  **固定一个数**：外层循环遍历 `nums[i]`，固定它。
2.  **转化为两数之和**：问题变成了在 `i` 后面的区间里，找两个数 `L` 和 `R`，使得 `nums[L] + nums[R] == -nums[i]`。
3.  **双指针查找**：
    *   `L` 指向 `i+1`，`R` 指向末尾。
    *   如果 `sum < 0`，说明太小，`L++`。
    *   如果 `sum > 0`，说明太大，`R--`。
    *   如果 `sum == 0`，找到了！

### 关键点：去重 (De-duplication)
这道题最麻烦的是**不重复**。我们通过排序和简单的判断来完美解决：
1.  **外层去重**：如果 `nums[i] == nums[i-1]`，说明这个数刚才算过了，直接 `continue`。
2.  **内层去重**：当找到一组解后，如果 `nums[L] == nums[L+1]`，说明下一个数还是它，会导致重复解，一直 `L++` 跳过。同理 `R--`。

### 复杂度
*   **时间复杂度**：O(N^2)。外层循环 O(N)，内层双指针 O(N)。
*   **空间复杂度**：O(1)（忽略存储结果的空间）。
